# BOAM Shiny App
This is an app that packages up a tool helps you simulate biodiversity offset scenarios based on user inputs.

The app can render model results into a pdf but to use this functionality you will need to install tinytext as follows:

install.packages("tinytex")
tinytex::install_tinytex()

You can verify that TinyTeX is working with:

tinytex::is_tinytex()
